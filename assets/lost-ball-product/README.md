## product-flyer-original.png

- 元ファイル名: `商品_ロストボール.png`(2026-08-19作成、提供元ローカルファイル)
- 2026-10-02にリポジトリへ追加(未改変・原本のまま。sha256で一致確認済み)
- 2894×4093px, PNG
- 内容: 販促フライヤー全体。上段に環境統計(「推定5億〜10億球」「毎年2100万球」)の説明文、下段左に商品(ロストボール＋「ひとりじゃないよプロジェクト」ステッカー)を手に持つ人物の写真、下段右に活動説明・会社情報(株式会社エンパワーアートラボ、代表取締役 山本裕子、住所)・QRコードを含む
- **この統計値(5億〜10億球／毎年2100万球)は、アカウント運営者が使用承認済み**(2026-10-02)。ただしDAY7本文・派生画像には含めていない(下記day7-product-photo.png参照)
- **「Sae株式会社」への寄付の記載あり**。DAY11のverified-facts確認待ち事項に関連する可能性があるが、今回のタスク(DAY7画像対応)では未反映。別タスクで対応予定

## day7-product-photo.png

- `product-flyer-original.png`の下段左(商品を持つ手の部分)のみをトリミングして作成した派生画像
- 1460×1850px, PNG
- 元画像からの**矩形トリミングのみ**(ピクセルの再描画・AI加工・商品の捏造は一切行っていない)
- 除外したもの: 人物の顔、会社情報(住所・代表者名)、フライヤー右側の大きいQRコード、上段の環境統計説明文
- 含まれるもの: 商品パッケージ(ロストボール6球＋「ひとりじゃないよプロジェクト」ピンクの木ステッカー)を持つ手・腕・胴体(白いチェック柄シャツ)。商品ステッカー自体に印刷された小さいQRコード2つは、実物の商品デザインの一部のためそのまま残している(これを消す加工は「商品の捏造」に該当するため行っていない)
- `data/draft-bank.json`の`lostball-day7-product-shop`の`media.path`として使用
