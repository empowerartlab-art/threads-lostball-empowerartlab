# 一人じゃないよプロジェクト 画像素材

「一人じゃないよプロジェクト」の紹介用に提供された画像素材を保存するフォルダ。

## sticker-100x70mm-v2-original.png

- 元ファイル名: `ステッカー100x70mm_350dpi【2稿】 (3).png`
- 2026-10-02 にリポジトリへ追加(未改変・原本のまま)
- 965×1378px, PNG
- 内容: 「ひとりじゃないよプロジェクト」のタイトル・タグライン(「人と地球をつなぐ福祉の輪」)、ハート型の木のイラスト(人物・犬・うさぎ)、QRコード2つ(ひとりじゃないよプロジェクト／就労継続支援B型エンパワーアートラボ)
- `data/verified-facts.json`の`product-includes-pink-tree-sticker`(ピンクの木のステッカー)の実物に対応する素材

## 用途

- 「一人じゃないよプロジェクト」「社会貢献」「子どもたちへの支援」関連投稿の補助画像として再利用可能
- 投稿用途に応じてQRコードの削除・トリミング等が必要な場合は、この原本から**派生画像を別ファイルとして作成**すること(この原本ファイル自体は改変しない)

## 注意

- 現時点(2026-10-02時点)で`.github/workflows/daily-live-post.yml`の自動投稿パイプライン(`lib/threads-client.mjs`の`createTextContainer`)はテキストのみの投稿にしか対応しておらず、画像添付機能自体が実装されていない。このフォルダの素材は将来の画像対応実装、または人間による手動投稿時の参照用。
- `data/draft-bank.json`の各投稿の`media`オブジェクトは`path`を1件しか持てず(配列ではない)、複数画像(カルーセル)運用にも現時点では対応していない。
